# Livewire-Rate-Limiter
======

## Installation

You can install the package via Composer:

```bash
composer require abolaradev/livewire-rate-limiter
```

You can publish and run the migrations with:

```bash
php artisan vendor:publish --tag='livewire-rate-limiter-migrations'
```

Then run the migrations:

```bash
php artisan migrate
```

You can publish the config file with:

```bash
php artisan vendor:publish --tag='livewire-rate-limiter-config'
```

Optionally, you can publish the views using:

```bash
php artisan vendor:publish --tag='livewire-rate-limiter-views'
```
